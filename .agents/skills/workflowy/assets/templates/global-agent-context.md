## Workflowy

For substantive personal or cross-project work, use the `workflowy` skill and
the connected Workflowy Desktop MCP. Read **AI Agent Workspace → ABOUT**.
Route named projects to their existing project under **PROJECTS** and work
without a named project to **PROJECTS → _general**, using topic branches
where useful. Keep private drafts, discussions, and evidence in the intended
branch for the operator and their authorized agents.

Date major sessions and substantive updates with a local ISO 8601 timestamp
and its offset. Link to an existing finding before adding a new record.
Use GLOSSARY for meanings, ENTITIES for named things, and REFERENCES for
citable sources. Follow ABOUT for the named fields and alphabetical order.
Use direct node links for specific relationships and native hashtags for
discovery. Read back each edit. If the connected Desktop MCP is unavailable,
continue the work and surface what still needs to be saved.
