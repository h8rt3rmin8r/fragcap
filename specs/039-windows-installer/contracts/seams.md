# Phase 1 Contracts: seams for S039

The crate-boundary and artifact contracts this slice adds or touches. Signatures
are the intended shapes; exact naming is fixed at implementation.

## 1. Path resolution (`fragcap-cli::paths`)

```rust
/// The per-user default hint-database location, a sibling of the profile dir.
/// `None` when the application-data base is unresolvable (mirrors
/// `user_profile_dir`). Pure: reads only the environment.
pub fn default_hint_db_path() -> Option<PathBuf>;   // %APPDATA%\fragcap\hint.db

/// UNCHANGED. Explicit source only: flag > FRAGCAP_HINT_DB > None.
pub fn hint_db_path(flag: Option<&Path>) -> Option<PathBuf>;
```

Contract: `hint_db_path` keeps its current three-way result and semantics.
`default_hint_db_path` is a new, independent resolver the `run` command layers on
top when `hint_db_path` returns `None`.

## 2. First-run bootstrap (`fragcap-cli::commands::run`)

```rust
/// Ensure the DEFAULT hint database exists. Pure over its arguments (tempdir
/// testable); performs filesystem side effects only on `default`.
///   - default exists            -> Ok(())            (untouched)
///   - default absent, template  -> fs::copy(template, default)
///   - default absent, no template -> Store::open(default) (empty schema)
/// Creates the parent directory as needed. Never consulted for an explicit path.
fn ensure_default_hint_db(default: &Path, template: Option<&Path>) -> io::Result<()>;
```

Caller contract in `run`:

```text
let explicit = paths::hint_db_path(args.hint_db.as_deref());
let (hint_db, from_default) = match explicit {
    Some(p) => (Some(p), false),
    None    => (paths::default_hint_db_path(), true),
};
if from_default {
    if let Some(def) = hint_db.as_deref() {
        // template = current_exe() sibling "hint.db", if it exists
        if let Err(e) = ensure_default_hint_db(def, template.as_deref()) {
            emitter.warn(... "hint database could not be initialized: {e}" ...);
        }
    }
}
// then, unchanged:
if let Some(path) = hint_db.as_deref() { accumulate_launch(path, emitter); }
let resolver = build_resolver(hint_db.as_deref())?;
```

Invariants preserved: `accumulate_launch` still no-ops on an absent file and never
creates it; `build_resolver` still treats absent-Ok(false) as non-fatal and
unopenable-Err as loud (FR-002, FR-004). A bootstrap failure is a warning, not an
error return (FR-005).

## 3. Barebones seed (`assets/hint-seed.json`)

Contract: a `kind:"export"` document that validates against the export subschema
with an empty record set, such that:

```text
fragcap targets import assets/hint-seed.json --db hint.db   # exit 0, valid v2 store
fragcap targets export --db hint.db                         # valid empty kind:"export"
```

No new code; the existing `targets import`/`export` paths are the producer and the
round-trip validator.

## 4. Installer (`wix/main.wxs`)

Contract (declarative, verified at build/manual time, not by `cargo test`):

- Product/Package: per-machine, `ProgramFiles64Folder\fragcap`, `ProductVersion`
  from the crate version, frozen `UpgradeCode`, `MajorUpgrade`.
- Components: `fragcap.exe` (keypath, with a system-path `Environment` element
  `Part=last`), `hint.db` (read-only), `LICENSE`, `NOTICE`.
- Add/Remove: standard entry with an About URL.
- Custom actions: deferred elevated `Add-MpPreference`/`Remove-MpPreference` on
  install/uninstall, `Return=ignore`, `INSTALLDIR` passed via `CustomActionData`.
- UI: `WixUI_InstallDir` with the exit-dialog optional checkbox opening
  `https://npcap.com` via `WixShellExec`; `wix/License.rtf` shown on the license
  screen.
- Unsigned.

## 5. Release workflow (`.github/workflows/release.yml`, pinned)

Contract additions to the `artifacts` job:

- Install WiX v3 and `cargo-wix` before building the installer.
- Build the barebones DB: `fragcap targets import assets/hint-seed.json --db <hint.db>`
  using the release-built CLI.
- Build the MSI: `cargo wix ...` into `dist/`.
- Archive: copy `hint.db` into the zip stage beside `fragcap.exe` (alongside
  `LICENSE`, `NOTICE`).
- Loose DB: copy `hint.db` into `dist/`.
- Checksums: broaden from `*.zip` to also cover `.msi` and `.db`, one `.sha256`
  per artifact.

The `release` job is unchanged: `gh release create ... dist/*` uploads every
artifact and checksum.

## 6. Documentation / glossary / spec (contract with the docs gate)
