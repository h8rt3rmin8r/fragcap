# Quickstart: Validate S205

## Prerequisites

Use Windows with installed Npcap, the verified signed WinDivert component, an elevated session for the explicit route, and an exact cold controlled client. A candidate MSI must have verified restoration bytes for the published v0.11.0 installation before local replacement. The controlled cloudbase peer is temporary, unprivileged, and leaves no remote files or service.

## Driver-free checks

Run the focused route, correlation, report, and CLI fixture suites first. They must include positive and negative TCP and UDP proof, passive packet availability, queue and writer loss, partial source, recipient access, Doctor, and terminal human/JSON parity. Run the full repository gate with the following command after implementation:

```sh
cargo xtask ci
```

## Physical route and package checks

Run the candidate ZIP and MSI controlled entry points against the external peer for IPv4 and IPv6 with the required native route stream. Run the signed-driver library matrix separately with route diagnostics on and off. Send three paired sentinels before activation, three while the selected connection is held open after its exact reply, and three after cleanup; enforce the larger of 50 ms and four times baseline for the candidate. Record exact client and peer bytes, sentinel counts and latency, selected route events, proxy leg, loss, bundle artifacts, effective native paths, Doctor and cleanup. Run a published v0.11.0 comparison as a separate baseline. Verify the cloudbase ports are closed after each run.

Observe both original-present and original-absent Npcap packet cases from actual passive artifacts, and reconcile each against the same route proof across compatibility, terminal calibration, target store, and later admission. Never mark a fixture as a physical observation.

## Hosted and review gate

Run the repository's Windows native integration and package certification tiers on the exact PR head. Read all CI and Codex/security review results, resolve comments, and request no more than one explicit second review round. The owner performs the final review and merge.
