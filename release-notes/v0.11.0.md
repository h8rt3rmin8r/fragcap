# Highlights

v0.11.0 adds a signed, explicitly selected direct route for supported Windows game sockets in Deep Capture.

- Managed launches can inspect launcher and client traffic together, while an exact game-only selection keeps other application traffic in a blind relay.
- The direct route combines child proxy settings with final-client TCP and supported UDP routing, including HTTP, TLS, and QUIC paths qualified by controlled Windows checks.
- Calibration records direct-route evidence separately from earlier proxy-only facts, and packet attribution requires independent original-flow evidence.
- MSI and ZIP packages carry the signed WinDivert component, its license, and corresponding source. Npcap remains a separate prerequisite for live packet capture.
- The release also improves managed-helper cleanup and TLS failure reporting, and updates bundled SQLite to 3.54.1.

The direct route passed controlled Windows tests, and release packages undergo exact certification before publication. Private-title and unelevated local MSI upgrade outcomes remain unverified.

For the complete change history, implementation details, and issue references, see the [full v0.11.0 changelog](https://github.com/h8rt3rmin8r/fragcap/blob/v0.11.0/CHANGELOG.md).
