# Windows qualification contract

Official MSI and ZIP executables must start version, help, and Doctor on clean supported Windows without a developer CRT. Absent Npcap is a Doctor readiness result after startup. Actual candidate PE imports must match the reviewed contract.

Package lifecycle validation uses synthetic user-state sentinels and separately checks install, repair, uninstall, executable ownership, and preserved data. A prepared CI runner import check does not prove clean guest startup.

The physical matrix stages exact bytes and runs seven required rows. The ordinary-user row expects blocking privilege refusal for live Capture and Deep Capture. Refresh the official v0.10.8 reference only from exact published bytes and current provenance; candidate evidence is separate. Historical references stay historical. No skipped rows or weakened freshness.
