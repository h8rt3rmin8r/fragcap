# S177 First-Use Contract Requirements Checklist

**Purpose**: Review the quality of S177 requirements before implementation.
**Audience**: PR author and reviewers.

## Completeness

- [x] CHK001 Are current-token privilege and machine prerequisites specified as independent Doctor facts? [Completeness, Spec FR-001]
- [x] CHK002 Are human, structured, exit, and post-fix readiness outcomes all specified? [Completeness, Spec FR-002]
- [x] CHK003 Is the setup-only state defined only after verified persistence, with explicit non-reachability meaning? [Completeness, Spec FR-004]
- [x] CHK004 Are refusal and unchanged-target cases named for stale, altered, declined, and incomplete confirmations? [Coverage, Spec FR-005]
- [x] CHK005 Do help requirements cover generated usage, missing-flag refusal, example line boundaries, and sensitive-option consequences? [Completeness, Spec FR-007 to FR-009]

## Clarity and consistency

- [x] CHK006 Does the term `ready` mean executable live readiness in the current process across human, JSON, and exit results? [Clarity, Spec US1]
- [x] CHK007 Is setup completion distinguished from calibration workflow completion and reached-client evidence? [Consistency, Spec US2]
- [x] CHK008 Is the exact structured authorization line specified as identifier plus one LF, with CRLF explicitly refused? [Clarity, Spec FR-006]
- [x] CHK009 Is `--launch` required in both parser-facing help and the described runtime behavior? [Consistency, Spec FR-007]

## Measurability and boundaries

- [x] CHK010 Can controlled tests establish both privilege verdict classes without relying on a real title? [Measurability, Spec SC-001]
- [x] CHK011 Can a setup-only then next-invocation test establish persistence and absence of reachability claims? [Measurability, Spec SC-002]
- [x] CHK012 Is the 80-column copyability criterion objective and bounded? [Measurability, Spec SC-004]
- [x] CHK013 Are offline replay, unrelated JSON/silent behavior, bundle cleanup, storage schema, and release publication explicitly outside the changed contract? [Scope, Spec Edge Cases and Assumptions]
