Published baseline: [v0.10.0](https://github.com/h8rt3rmin8r/fragcap/releases/tag/v0.10.0).

v0.10.0 was published on 2026-09-15 after S150 preparation and the operator's separate explicit publication authorization. It contains the stable version-one Rust API, guided target registration/setup and resumable calibration, current native documentation, session/help UX, dependency maintenance and bounded writer correction since v0.9.0. It does not claim universal compatibility or independent audit completion. The [short notes](../../release-notes/v0.10.0.md) summarize user-visible changes separately from the assembled changelog. S151 diagnostics are unreleased.

## Historical S150 preparation boundary

The existing `release.toml` permits local version-only Cargo release operations on `release/*`. S150 therefore uses `release/0.10.0`, overriding the usual `codex/` feature prefix solely for that established policy. Spec-kit artifacts remain at `specs/150-native-review-release`. The main-only `New-Release.ps1` orchestration is not run from this in-progress branch, and its native child launches are not used on the desktop. Instead, configured Cargo release, exact embedded/portable identity updates, existing golden generators and changelog assembly run through verified hidden, redirected launchers with targeted staging. No release policy, package budget, crypto provider, publication workflow, or historical physical measurement is weakened.

The aggregate Cargo release dry run prints a Publishing banner even with publication disabled. S150 therefore previews and executes only `cargo release version 0.10.0 --workspace --config release.toml`, with `--execute --no-confirm` only on the second invocation, then commits the local manifest/lock result separately. No aggregate release execution is used; the version subcommand has no publication, tag or push step.

Two fresh fixed-code Windows campaigns individually passed all fourteen cases with zero hard failures and agreed within the existing diagnostic tolerance. This clears the bounded engineering verification finding, not the precise historical host stall or independent #333 installed-build retest. Current-head CI, human merge review, exact tag/package certification and publication controls still apply.
