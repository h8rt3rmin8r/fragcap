# Highlights

- Deep Capture now keeps managed routing and installation trust in place until the relevant processes have exited, and reports an incomplete shutdown when it cannot prove that release is safe.
- Ordinary Deep Capture can observe for up to five minutes, with the effective duration shown before and after the session. Calibration keeps its shorter limit.
- Windows installation now provisions one machine-specific CA for Deep Capture across user accounts. A first install removes identified pre-S185 Fragcap state; repair, startup, and Doctor verify the installed signer and exact trusted root.
- Current documentation and published-package replay now identify the independently verified v0.10.9 release.

For the complete change history, implementation details, and issue references, see the [full v0.10.10 changelog](https://github.com/h8rt3rmin8r/fragcap/blob/v0.10.10/CHANGELOG.md).
