# Highlights

- Deep Capture now keeps its session proxy available while a managed Steam, direct, or publisher launch closes normally, within a separate bounded route-owner release interval.
- If a launched application remains open or its state cannot be established, fragcap reports incomplete route cleanup and gives a close-and-relaunch recovery step.
- The Windows platform workflow now uses a read-only repository token.

These controlled corrections do not establish compatibility with every title or environment. No real-title field trial is claimed for v0.10.5.

For the complete change history, implementation details, and issue references, see the [full v0.10.5 changelog](https://github.com/h8rt3rmin8r/fragcap/blob/v0.10.5/CHANGELOG.md).
