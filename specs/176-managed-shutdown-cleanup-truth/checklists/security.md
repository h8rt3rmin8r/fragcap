# S176 Security and Lifecycle Checklist

- [x] The constitution adds only exact Deep Capture process control with named rights and no memory rights.
- [x] The authorization plan must expose the exact controlled scope, deadlines, and unsaved-progress consequence before effects.
- [x] Session launch receipt, process-object identity, creation time, path, account, session, and ancestry are required together.
- [x] Warm, escaped, same-name, reused-PID, unrelated-title, and ambiguous processes are refused.
- [x] Graceful close is process-bound and force is limited to exact still-owned owners.
- [x] Route release depends on verified exit; request success alone is insufficient.
- [x] Proxy and trust lifetime, failure evidence, and recovery order are covered.
- [x] Doctor never turns historical failure into a successful past session because a journal is readable.
