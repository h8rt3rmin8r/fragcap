# Highlights

- Deep Capture's native QUIC observation path now has bounded queue headroom and an independent retained-payload cap, with counted loss when either bound is reached.
- Interactive Doctor, target registration, and warm-restart questions now accept keyboard answers. Doctor reports prompt I/O failures instead of presenting them as operator declines.

This release does not establish a fragcap-specific cause or correction for focus-dependent Print Screen behavior.

For the complete change history, implementation details, and issue references, see the [full v0.10.3 changelog](https://github.com/h8rt3rmin8r/fragcap/blob/v0.10.3/CHANGELOG.md).
