# Contract: Homepage Target Specimen

The homepage shows one static human-output specimen with:

- `TARGET`, `CAPTURE`, `ENGINE`, and `SENSITIVITIES` columns in current order;
- two clearly synthetic target handles;
- placeholder engine and sensitivity values that are not title compatibility claims;
- the exact `Next command:  fragcap capture 1` footer; and
- no actual game title, local path, account, host, or endpoint.

The specimen remains hand-authored because the static site build has no local target store. Its vocabulary is checked against the CLI contract during S078 verification.
