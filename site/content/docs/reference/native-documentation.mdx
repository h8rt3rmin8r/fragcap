## Executable example authority

Every current `fragcap` invocation in the README and nonhistorical site pages passes through the production command parser without dispatch under the applicable command trees. Retired Deep Capture consent switches remain rejected. Parser acceptance proves the command shape, not that an installed command ran or that its target is compatible.

Committed manifest specimens pass through the versioned product reader. Packet pcapng and JSON Lines examples remain exact generated goldens. Application, HAR, process, proxy, cleanup, correlation and stable API examples use controlled product tests when a shortened standalone specimen would omit lifecycle or authority facts. JSON syntax alone is never accepted as product authority.

## Engineering completeness and explicit non-claims

Deep Capture is native and shipped for known-compatible stored targets. The current source has controlled protocol, routing, launch, evidence, cleanup, recovery, packaging, API and documentation contracts. It does not claim universal decryption, certificate-pinning bypass, compatibility with an unmeasured title, or that an independent security audit has been performed.

Current source also carries requested inspection scope, effective scope,
middleware handling, and policy identity through calibration, authorization,
stored facts, artifacts, Targets, and Doctor. Launcher-mediated `auto` selects
exact-game inspection with blind middleware relay. Scope-specific repository
and package checks establish the implemented contract; installed-product
observations follow release.

Green CI, package certification, hosted replay, bot review and this closed inventory are engineering evidence, not proof of universal live-title compatibility or independent security acceptance. Optional operator and reviewer observations are not standing implementation-completion conditions.

## Reconciliation point

Later field or independent-review findings amend the current contract at the page and executable authority that owns the affected fact. They are not inferred in advance. Each observed failure becomes a concrete defect against the affected active release, with reproduction or evidence, expected and actual behavior, remediation and regression coverage as applicable.

Optional installed reproduction uses digest-verified published bytes and records the actual operator decision for any trust or game launch effect. Installation, version output and controlled package tests do not establish real-title compatibility. Consent, scoped routing, reversible exact cleanup and retained administrator control remain unchanged. The MSI and fragcap executable are unsigned; the bundled WinDivert driver has separate upstream signing evidence.
