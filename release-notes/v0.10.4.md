# Highlights

- First-run Steam client setup now identifies launch metadata as a hint, guides a bounded observation or explicit declaration, and confirms a separate exact client plan before saving it.
- Cold Steam calibration now binds the managed platform root when Windows reports only its executable name, while keeping final-client acquisition and proxy reachability as separate observations.
- Failed calibration reports the earliest supported failure stage and retained evidence paths without repeated generic cleanup messages. The setup guide and target detail now distinguish stored launch roles from metadata hints.

These controlled corrections do not establish compatibility with every title or environment. An owner field trial can use published v0.10.4 bytes after release.

For the complete change history, implementation details, and issue references, see the [full v0.10.4 changelog](https://github.com/h8rt3rmin8r/fragcap/blob/v0.10.4/CHANGELOG.md).
