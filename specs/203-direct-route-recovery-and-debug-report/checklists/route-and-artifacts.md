# Domain Checklist: Route Evidence and Artifact Integrity

**Purpose**: Check S203 requirements before design and implementation.

**Created**: 2026-11-12

## Route and ownership

- [x] Exact final-client generation, original destination, and one-use receipt are distinct authorities.
- [x] Client-side handshake or datagram delivery is required separately from upstream proxy success.
- [x] Tuple reuse, competing owners, and missing socket evidence have named non-positive outcomes.
- [x] IPv4, IPv6, TCP, UDP, refusal, cancellation, and no-byte cases are named.
- [x] Unrelated traffic remains prompt pass-through with no payload diagnostics.

## Evidence and recovery

- [x] Route, passive packet, proxy, and process observations remain separate facts.
- [x] Queue and writer gaps, crash prefixes, missing artifacts, and clock uncertainty are explicit.
- [x] Manifest, Doctor, retention, cleanup, and share-copy behavior are included.
- [x] Export is a source-preserving derivation with stated sensitivity transformation.
- [x] Human, JSON, compatibility, target fact, and later admission must agree.

## Validation

- [x] Controlled non-loopback and packaged tests can establish the acceptance criteria.
- [x] Post-receive loss and unmeasurable pre-receive loss remain distinct.
- [x] No private title run or separate system-wide capture is required for issue closure.
