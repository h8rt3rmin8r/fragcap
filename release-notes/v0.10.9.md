# Highlights

- Calibration now has a finite observation window and records packet omissions against the exact connection time, making failed attempts easier to diagnose without calling them successful captures.
- A stored Steam target moved between libraries can be recovered through an exact preview and conditional update while keeping its authored identity.
- Deep Capture reconciles managed shutdown, helper exit and final proxy counts so cleanup and loss are reported from the completed session.
- Official Windows executables start without a separately installed Visual C++ runtime. The operator guide explains the corrected workflow and the Windows session CA trust prompt.
- The locked Tokio graph moves to 1.53.3 to address RUSTSEC-2026-0386, which affects Unix asynchronous file-descriptor registration. No Windows runtime exploit was demonstrated by the project.

For the complete change history, implementation details, and issue references, see the [full v0.10.9 changelog](https://github.com/h8rt3rmin8r/fragcap/blob/v0.10.9/CHANGELOG.md).
