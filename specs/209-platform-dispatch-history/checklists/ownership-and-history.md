# Domain Checklist: Launch Ownership and Capture History

- [x] The approved plan names first dispatch and any alternate before effects.
- [x] Warm platform inspection uses query-only identity proof and never process control.
- [x] Final-client generation and original destination gate selected direct routing.
- [x] An uncertain dispatch cannot cause a duplicate alternate launch.
- [x] A failed launch is retained as a failure, not converted into a positive compatibility fact.
- [x] History rows are private, bounded, ordered, and linked to the native target identity.
- [x] Comparison checks build, scope, route, and evidence comparability.
- [x] History cannot gate authorization or change the selected route.
- [x] Store migration preserves old rows and never backfills unobserved facts.
- [x] Interrupted cleanup and append failures remain separately visible.
