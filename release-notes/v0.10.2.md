# Highlights

- Windows Deep Capture startup and terminal observation handling are deterministic under scheduler pressure while retaining bounded queues, exact loss accounting, finite deadlines and cleanup authority.
- Published-package certification now uses structured proxy-start and reached-client evidence for positive success, while firewall containment, process ownership, non-loopback rejection and cleanup remain strict.
- Native product documentation and independent-review intake now have complete machine-checked contracts. This release does not claim that the external security review or final Deep Capture gate is complete.
