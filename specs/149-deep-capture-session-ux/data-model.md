# Data Model: S149

## Authorization Consequences

Input is the existing canonical plan. Output is human text only. Exact target name/identifier, launch case, route scope, trust action, bundle path, optional HAR/key-log/client-identity selection, payload retention, cleanup, and retained sensitivity derive from that plan. The canonical JSON and plan hash remain unchanged.

## Observed Counters

A fixed set of saturating counters tracks total observations and each existing inspectability class. A cumulative display is eligible at observation one and multiples of one hundred. No observation content or identity map is retained. Live ownership is explicitly unavailable until terminal reconciliation.

## Terminal Guidance

Input is the facade terminal report plus exact bundle evidence presence. Actual session outcome, artifact statuses, cleanup resource identities/statuses, and failures retain their independent meaning. Missing evidence is not called retained, and an unresolved cleanup result offers Doctor inspection rather than broad cleanup authority.
