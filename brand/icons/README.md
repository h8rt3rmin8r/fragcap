# fragcap icons

Six starter icons on a 24 grid: filter, file, clock, interface,
endpoint, search. They are the symbols the brand guide names.

Stroke is 1.5 with butt caps and mitre joins, and the stroke uses
`currentColor`, so an icon inherits whatever semantic token its
container sets (`--fc-fg`, `--fc-accent`, `--fc-warning`, ...).

Extend the set with direct technical symbols only. Never add
mascots, weapons, controllers, shields, hooded figures or generic
circuit-board decoration - see the prohibited treatments in
`README.md`.
