# Session and Process Contracts: S187

## CLI timing

`deep-capture --duration 10m --wait 5m` and `deep-capture --calibrate reachability --duration 2m --wait 2m` are accepted for otherwise eligible targets. Defaults remain 60 seconds observation and 30 seconds launch. `--duration 0`, `--wait 0`, values above 10 and 5 minutes respectively, or any unsupported direct facade deadline refuse before effects with the exact field and ceiling.

The authorization plan's canonical JSON keeps `deadlines_milliseconds` as effective values and adds a requested-duration object with explicit/default source and original milliseconds. The human plan renders the same canonical value. Terminal JSON and human summaries report requested and effective launch and observation values plus the separate capture-return allowance. Existing consumers can continue reading the effective keys.

## Steam topology

A Steam-anchored stored target may retain one client declaration or an ordered chain beginning with `launcher` and ending with `client`. Each stage uses an exact canonical executable path and unique role. The plan exposes platform root, ordered stages, and exact shutdown scope. A shim or helper outside this declaration is only observed and remains an exit obligation.

## Process trace and connection evidence

The versioned process trace names observed exact-root descendants with birth, exit, instance, parent instance when established, and explicit loss or omission totals. Visibility does not confer control authority.

An application connection retains a correlation state `exact`, `ambiguous`, or `unavailable` from first observation, with an instance identifier only when exact process and socket evidence support it. Existing packet-flow correlation remains independent. A pre-client connection cannot be reported as final-client traffic solely because the session later acquired the client.

## Timeout and recovery

On acquisition timeout, the proxy remains active through the finite route-owner release phase. Every exact declared owner and observed helper is reconciled to verified exit or a named unresolved obligation. Automatic control is restricted to exact preauthorized process objects; Doctor accepts only an exact exit prerequisite before clearing retained route state.
