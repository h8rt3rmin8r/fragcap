# Highlights

- Guided calibration now handles target registration, executable setup, stable candidate choices, and resumable operator pauses with fresh, separate authorization for every effect.
- A stable version-one library API exposes the same lifecycle, adapters, typed outcomes, and cooperative cancellation without a CLI dependency.
- Current native documentation explains packet/application authority, sensitive bundles, exact recovery, migration, and final-package certification. An independent-review handoff is ready; the audit and Deep Capture completion gate remain open.
- Dependency security maintenance updates the native TLS stack. Operator validation is intended for these newly published bytes, not agent-run games or installed sensitive software.

For the complete change history, implementation details, and issue references, see the [full v0.10.0 changelog](https://github.com/h8rt3rmin8r/fragcap/blob/v0.10.0/CHANGELOG.md).
