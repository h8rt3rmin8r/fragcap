# Quickstart: S165 Route Owner Lifetime

1. Prepare and authorize an ordinary Deep Capture or calibration plan as before. The plan now shows the bounded route-owner release interval.
2. When capture ends, close the launched game and any Steam or publisher launcher named by fragcap using each application's normal Exit control. Fragcap keeps the session proxy active during the displayed interval.
3. If the interval expires, the session reports partial cleanup. Close the named application normally and relaunch it outside the old session before using its networked features again.
4. If fragcap itself ended unexpectedly, close any application it launched normally and relaunch it before using its networked features. Inspect the previous session and Doctor for other cleanup obligations.

Controlled tests validate the release ordering and recovery report. They are not a claim that a real title is compatible with Deep Capture.
