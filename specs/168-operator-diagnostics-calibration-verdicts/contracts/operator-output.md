# S168 operator output contract

## Alignment

For every adjacent column, next anchor = previous anchor + maximum actual preceding visible width + 4. ANSI does not contribute width; controls are visibly escaped. Optional keys/headings participate. Continuations hang at the computed anchor. No narrow-width exception is authorized.

## Discovery and Doctor

Discovery source headings are flush left, preceded by 80 underscores. Target headings indent four spaces, child keys eight spaces, values share the report-wide anchor and default color. Every candidate and finding remains exact and ordered deterministically. Doctor defaults to concise healthy-history counts, keeps every actionable finding and scan limitation, and --history-details exposes the original human details; JSON stays exact.

## Calibration

Chapters describe plan, authorization, launch/observation, action required, result, evidence, cleanup, and next action. Current-case readiness is separate from attempted verdict; neither finalization nor HTTP status establishes target ownership. Completed exchanges, failed connections, records and phase windows have independent labels. Missing correlation names #468. Accessible/written/partial/omitted status remains distinct, and #464 is named for inaccessible retained evidence. One supported next command is shown with prerequisites; no command exists is explicit when unresolved. Canonical plan and exact consent binding remain fully reviewable. Quiet/silent/JSON/color policy remains compatible.
