# S184 session lifecycle contract

## Owner release

1. Select all exact proven owners without discarding them because one same-named event is unresolved.
2. Request graceful close only for proven live owners. At the authorized grace boundary, force only owners whose exact identity is still verified. Verify exit after either path.
3. Complete the watcher and reconsider late events and helpers before declaring route-owner release.
4. Any unresolved plausible routed process produces incomplete route-owner, route, and target-route truth. A local environment-lease cleanup result does not establish process exit.
5. Keep proxy and trust until the bounded owner-release decision. If a plausible live owner remains, retain exact recoverable trust and report proxy continuity unavailable after its finite shutdown.
6. Before any Doctor replay of an incomplete route, use the synchronized resource journal's route-owner exit prerequisite to verify that every observed plausible routed process has exited. If event authority or exit verification is incomplete, leave route and trust obligations unchanged and retain the session owner registry entry.

## Duration

1. Calibration: effective observation is at most 60 seconds and remains visible in the plan.
2. Ordinary: default is the existing finite default; an explicit positive duration through five minutes is accepted without shortening. Zero and above-five-minute values are refused before effects.
3. The plan and terminal record distinguish the requested Capture observation span from a finite Capture return allowance. The adapter runs Capture for the full accepted span unless an independent named stop reason occurs.
4. The facade must not apply an additional hidden cap to an accepted plan.

## Controlled evidence

- Exact root and final client plus same-name unproven event: exact owners controlled and exited, unknown receives no control, overall route status truthful.
- Ambiguous, late, reused, escaped, or unverifiable event: no control without exact proof; incomplete route and recovery obligations recorded.
- Installed controlled ordinary target with duration over one minute: plan, actual arm-to-stop, capture span, terminal, and cleanup reconcile.
