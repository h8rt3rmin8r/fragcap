# CLI and evidence contracts

An existing anchored target is never changed by `targets add`. A dedicated bounded recovery action presents exact old/new roots, anchor, preserved fields, and a proposal digest. Exact confirmation applies only after fresh store/platform validation. Errors identify unavailable, ambiguity, changed executable, old root still present, or unchanged location. Calibration resume revalidates target and measurement applicability.

The facade owns an absolute observation deadline. Real Capture derives duration from remaining time and finite completion margin. Setup, observation, drain, and shutdown remain separate. A normal return within budget succeeds; late return fails.

Each omission has cause, count, and bounded time scope. Proven nonoverlap may be ignored for a connection. Unknown global loss, overlapping omissions, conflicting ownership, and reuse refuse positive correlation. Proxy/application populations distinguish observed zero from unavailable. Final cleanup may update terminal count authority but not observation eligibility.

Only exact session-created owners may receive graceful or force requests. Helpers are observed while owner requests proceed. Route release requires confirmed exits and complete watcher evidence.
