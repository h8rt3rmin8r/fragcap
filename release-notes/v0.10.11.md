# Highlights

- Ordinary Windows users no longer receive a false installation CA repair warning when the public root is healthy and the signer correctly restricts private metadata. Deep Capture still proves the signer before starting.
- HTTPS CONNECT accepts an equivalent inner authority without an explicit port, using the HTTPS default of 443. Distinct authorities and stalled headers retain separate diagnoses.
- HTTPS compatibility requires completed HTTPS evidence; partial HTTPS traffic cannot inherit a completed plain HTTP result.
- Current documentation and published-package replay identify the independently verified v0.10.10 release.

For the complete change history, implementation details, and issue references, see the [full v0.10.11 changelog](https://github.com/h8rt3rmin8r/fragcap/blob/v0.10.11/CHANGELOG.md).
