# Highlights

v0.10.13 improves managed Deep Capture acquisition for cold Steam and publisher launches when Windows reports only an executable name.

- Fragcap verifies a candidate's exact executable path against its process instance before binding a declared stage. Wrong paths, stale instances, and missing proof remain explicit limitations.
- An acquisition timeout reaches the top-level CLI result while packet, proxy, manifest, and cleanup evidence retain their separate outcomes.

The combined live ETW and Npcap regression for issue #547 remains open; this release does not claim installed-title validation.

For the complete change history, implementation details, and issue references, see the [full v0.10.13 changelog](https://github.com/h8rt3rmin8r/fragcap/blob/v0.10.13/CHANGELOG.md).
