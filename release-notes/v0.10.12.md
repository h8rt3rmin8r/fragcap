# Highlights

- Deep Capture now honors explicit observation requests up to ten minutes and managed launch requests up to five minutes. Its plan and retained evidence show the requested and effective limits.
- Cold Steam launches can include declared publisher stages. Process and proxy evidence identify the exact owned process when it can be verified, and report an evidence gap when it cannot.
- Installed-product field test guidance now uses Fragcap's default data and session locations and records the effective paths.

For the complete change history, implementation details, and issue references, see the [full v0.10.12 changelog](https://github.com/h8rt3rmin8r/fragcap/blob/v0.10.12/CHANGELOG.md).
