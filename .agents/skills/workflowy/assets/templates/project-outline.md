# Named project outline template

Paste the outline into the named project branch. Replace placeholders, omit optional fields without values, and include `spec-kit` where the project uses it. Add `epic` only for documented membership. Use the same dated shape under Personal notes.

```text
- project-name
  - info
    - tags
      - #project-name
    - links
      - <primary repository or project URL>
      - <official tracker or documentation URL>
    - details
      - <durable purpose and scope>
      - current_state
        - <latest supported result>
      - next_actions
        - <specific action>
      - evidence
        - <direct evidence link>
  - spec-kit
    - S094 Check source order
      - date
        - 2026-11-20T10:15:00-05:00
      - date_basis
        - Integration
      - epic
        - <linked epic title>
      - scope
        - <short description>
      - evidence
        - <permanent spec link>
        - <pull request link>
  - notes
    - 2026-11-20T10:20:15-05:00
      - title
        - Reviewed source order
      - tags
        - #project-name
      - details
        - <what happened and what it established>
      - related
        - <link to S094>
```
