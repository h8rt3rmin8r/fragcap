# Highlights

v0.10.14 strengthens managed Deep Capture continuity, game-only inspection, guided calibration, and Windows storage consistency.

- Managed launches can bind an exact successor after a client handoff, begin the requested observation after verified acquisition, and retain bounded connection-stage, failure, and phase-time diagnostics.
- Windows defaults now use the current account's `.fragcap` directory across ordinary and packaged launches, with careful legacy database and profile preservation.
- Native exact-game inspection can blind-relay launcher and middleware traffic without retaining excluded application content or creating proxy-owned TLS keys for it.
- Calibration and Deep Capture share `auto`, `game`, and `launch-chain` scope selection, with exact compatibility dimensions and separately authorized bounded retry or packet-only fallback.

Installed-product and private-title observations occur after publication; any concrete failure returns as a version-specific issue.

For the complete change history, implementation details, and issue references, see the [full v0.10.14 changelog](https://github.com/h8rt3rmin8r/fragcap/blob/v0.10.14/CHANGELOG.md).
