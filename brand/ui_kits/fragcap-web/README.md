# fragcap-web

A demo product page built entirely from the design system. Open `index.html`
directly; it links `../../styles.css` and `../../components/components.css`
and uses no other stylesheet.

It exists to prove the system holds together, and to show the register the
brand asks for: state what the tool is, show one worked invocation with
representative output, name the prerequisite plainly, link to documentation.
No testimonials, no feature grids, no urgency, no generalised calls to action.
