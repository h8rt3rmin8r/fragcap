# Highlights

v0.11.2 streamlines Deep Capture around the final game and improves the evidence produced when direct routing is incomplete.

- An ordinary attempt no longer requires separate calibration. Steam-associated games use a verified Steam launch, while publisher launchers keep their normal network path.
- Direct routing now tracks packet and process ownership through socket closure and reuse, with bounded retries and explicit loss outcomes.
- Test cleanup enforces owned temporary roots, and the QUIC dependency updates address three RustSec advisories.

The latest code has passed local checks, but final-head physical packet delivery and an installed ESO run remain unverified. Earlier controlled readback found five lost selected packets and one missing UDP finish; [issue #594](https://github.com/h8rt3rmin8r/fragcap/issues/594) remains open.

For the complete change history, implementation details, and issue references, see the [full v0.11.2 changelog](https://github.com/h8rt3rmin8r/fragcap/blob/v0.11.2/CHANGELOG.md).
